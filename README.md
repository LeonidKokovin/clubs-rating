# Рейтинг клубов

Одностраничный сайт с рейтингом клубов. Проект новый и с сайтом
englishleonid.ru не связан — тот живёт в отдельном репозитории
`englishleonid-site`.

## Структура

Страница целиком лежит в `index.html` в корне репозитория.
Картинки и прочие файлы — рядом, в подпапках (`img/` и так далее).

## Как работать

```bash
git clone https://github.com/LeonidKokovin/clubs-rating.git
cd clubs-rating
# правки в index.html
git add -A
git commit -m "что изменено"
git push
```

## Договорённости

- Переводы строк не преобразуются (см. `.gitattributes`) — файл должен
  попадать на хостинг байт-в-байт таким, каким его сделали.
- Пароли, токены и ключи в репозиторий не кладём ни при каких условиях.
- Где будет размещён сайт, пока не решено.
